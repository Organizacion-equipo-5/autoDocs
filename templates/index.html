Cómo funciona

Arquitectura moderna y desacoplada. Desde el upload hasta el PDF en 5 pasos.

01

Subir proyecto

Sube un .zip, .tar.gz o conecta tu repo de GitHub directamente desde el dashboard.

02

Análisis estático

El motor Python usa AST para analizar funciones, clases, imports y detectar endpoints de API.

03

Generación de docs

DocGenerator produce README, referencia de API, documentación de clases y arquitectura del proyecto.

04

Dashboard visual

React muestra métricas de calidad, diagramas de estructura y la documentación navegable.

05

Exportar

Descarga PDF, Markdown o HTML en un clic, listo para entregar o publicar en GitHub Pages.
