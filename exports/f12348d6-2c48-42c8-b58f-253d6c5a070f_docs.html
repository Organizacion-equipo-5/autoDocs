Descripción: 1. Propósito del endpoint (¿para qué sirve?)
Este endpoint permite a la aplicación “leer” el archivo llamado .env que está dentro del proyecto. Ese archivo contiene datos de configuración (por ejemplo, contraseñas, nombres de usuario o direcciones de servidores) que la aplicación necesita para funcionar correctamente. En palabras muy simples, es como abrir un cajón donde se guardan las llaves que abre otras partes del programa.

2. Qué hace este endpoint (funcionalidad)
Cuando alguien hace una petición GET a la ruta .env, el servidor de Django abre el archivo .env que está en el proyecto, extrae su contenido y lo devuelve como texto plano. No modifica nada; solo muestra lo que hay escrito en ese archivo.

3. Qué información necesita para funcionar
No necesita que el usuario envíe datos ni parámetros especiales. La única “información” que requiere es que el archivo .env exista en la ubicación esperada dentro del proyecto (en la carpeta donde está el código). Si el archivo no está o el servidor no tiene permiso para leerlo, simplemente no podrá responder con éxito.
