POST /login

Descripción: 1. Propósito del endpoint (¿para qué sirve?)
Este recurso sirve para que un usuario pueda entrar a la aplicación. Es como la puerta de entrada: cuando alguien escribe su nombre de usuario y su contraseña, el sistema verifica que esos datos sean correctos y, si lo son, le permite pasar al interior y usar las funciones de la aplicación.

2. Qué hace este endpoint (funcionalidad)
Al recibir la petición, el programa:

  1. Toma los datos que el usuario envía (usuario y contraseña).
  2. Busca en la base de datos si esos datos coinciden con una cuenta registrada.
  3. Si la combinación es correcta, genera un “token” (una pequeña llave digital) que identifica al usuario durante su sesión.
  4. Devuelve esa llave al cliente para que la guarde y la envíe en las próximas solicitudes, de modo que el servidor sepa que quien habla es el mismo usuario autenticado.

En caso de que los datos no sean válidos, responde diciendo que el inicio de sesión ha fallado.
